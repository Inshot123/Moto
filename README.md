# MotoGear PH — Setup Instructions (XAMPP + MySQL)

1. Extract the `motogear` folder into your XAMPP `htdocs` directory (e.g., `C:\xampp\htdocs\motogear\`).
2. Start **Apache** and **MySQL** in the XAMPP Control Panel.
3. Open `http://localhost/phpmyadmin` in your browser, click **Import**, and upload `database.sql`.
4. Open the Storefront at `http://localhost/motogear/index.php` and the Admin Portal at `http://localhost/motogear/admin.php`.

**Default Accounts:**
- **Admin:** `admin` / `admin`
- **Customer:** `rider` / `123`
